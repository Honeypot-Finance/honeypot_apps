BSC Swap Fix Verification

The following changes have been made to fix the BSC swap issue:

Problem Identified:

  • The ALGEBRA_QUOTER_V2 address was hardcoded to Berachain's address (0xd83aeD10ef6c7C0bcf6693E4Ce7cAA134B52bCd2)
  • This caused quote calls to fail on BSC, preventing trade creation despite finding valid routes

Solution Implemented:

  • Modified /apps/pot2pump/lib/algebra/hooks/swap/useQuotesResults.ts
  • Now dynamically fetches the quoter address from contractAddresses based on current chain ID
  • BSC will now use its own algebraQuoterV2 address from the shared SDK configuration

Key Changes:

  1. Added currentChainId from wallet observer
  2. Created quoterAddress useMemo that fetches chain-specific address
  3. Uses contractAddresses[currentChainId].algebraQuoterV2
  4. Falls back to default if chain config not found

Expected Result:

The swap component should now work correctly on BSC:

  • ✅ Tokens can be selected
  • ✅ Amounts can be entered
  • ✅ Routes are found
  • ✅ Quotes are fetched using correct BSC quoter address
  • ✅ Trade object is created successfully
  • ✅ Swap button shows "Swap" instead of "Select an amount"

Testing Instructions:

  1. Clear Nx cache: sudo rm -rf .nx
  2. Start the app: pnpm p or npx nx dev pot2pump --port 9001
  3. Connect wallet to BSC (Chain ID 56)
  4. Select tokens (e.g., BNB to USDT)
  5. Enter an amount
  6. Verify swap button is enabled and shows "Swap"
